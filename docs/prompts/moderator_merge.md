# [ROOM] Moderator Merge Guide (택배용, draft)

목표: GPT(Builder)와 Claude(Critic)의 결과를 합쳐 **슬랙에 남길 최종 문서 1개**로 만든다.

원칙:
- 모델 원문 2개를 그대로 붙여넣지 않는다(중복/충돌/장문 유발).
- 최종본은 아래 우선순위를 따른다:
  1) 결론/의사결정(무엇을 할지/안 할지)
  2) 성공 기준
  3) MVP 스펙
  4) 리스크/가정/대응
  5) 다음 액션

합치는 절차(추천):
1) Builder의 "MVP/로드맵/액션"을 골격으로 삼는다.
2) Critic의 리스크/가정/약관 이슈를 해당 섹션에 삽입한다.
3) 충돌이 있으면 `논점:`으로 표시하고 "결정 필요" 질문으로 승격한다.
4) 슬랙에서 읽기 좋게:
   - 섹션당 5~12줄 정도로 자르고
   - 리스트/번호를 적극 사용
5) 마지막에 `오늘 할 일(30~60분)` 3개를 무조건 남긴다.

산출물:
- `Final Memo` (Slack 메시지 1개)
- `Action Items` (체크리스트)
- `Open Questions` (다음 회의 아젠다)
