# Docs (Core Only)

이 레포는 `docs/` 문서를 **최소 세트(Core 5개)** 로만 유지합니다.

## Core 5
- `docs/README.md`
- `docs/ROOM_FLOW.md`
- `docs/decision/DECISION_LOG.md`
- `docs/owner/PROJECT_TODO.md`
- `docs/developer/COMMAND_SPEC.md`

## 원칙
- Core 외 문서는 만들지 않습니다.
- 프롬프트는 레포에 저장하지 않고 외부(벤더 콘솔/Agent 설정 등)에서 관리합니다.
- 삭제된 문서가 필요하면 Git 히스토리에서 확인합니다.
