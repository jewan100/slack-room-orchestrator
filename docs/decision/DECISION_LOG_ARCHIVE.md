# DECISION LOG ARCHIVE

`DECISION_LOG.md`에서 대체/종료되어 제외된 과거 결정을 보관한다.

## 참조 원칙
- 이 문서는 아카이브 전용이다.
- AI 워커 기본 참조 대상이 아니다.
- 사용자/리뷰어가 명시적으로 요청한 경우에만 읽는다.
- 모든 과거 결정을 무제한 보관할 필요는 없으며, 필요 시 항목을 추가 압축/삭제한다.

## 이동 규칙
- `DECISION_LOG.md`는 현재 유효 결정만 유지한다.
- 상태가 `대체됨`, `종료`, `무효`가 되면 이 문서로 이동한다.
- 이동 시 원문 구조(`주제/영향 범위/결정/근거/후속 액션/상태`)를 유지한다.
