# COMMAND_SPEC

이 문서는 Slack 기반 아이디어 브레인스토밍 회의실의 MVP 커맨드 스펙을 정의한다.

## 공통 규칙
- 모든 커맨드는 회의 세션 컨텍스트(`roomSessionId`)를 기준으로 동작한다.
- 세션이 없는 상태에서 실행 가능한 커맨드: `/room start`만 허용.
- 응답은 가능하면 **짧은 요약 + 다음 액션** 형태로 제공.
- 에러 메시지는 원인/해결 가이드를 함께 제공.

## 상태 모델 (요약)
- `IDLE`: 세션 없음
- `PREPARED`: `/room start` 완료
- `RUNNING`: `/room launch` 완료 (토론 진행)
- `DECIDED`: `/room decide` 완료

---

## 1) `/room start <topic>`

### 목적
회의를 시작하고, 토론 전 필요한 맥락(문제정의/목표/제약)을 수집한다.

### 입력
- `topic` (필수): 논의 주제

### 선행 조건
- 기존 활성 세션이 없거나, 이전 세션이 종료(`DECIDED`) 상태여야 함

### 처리
1. 새 `roomSession` 생성
2. 주제/생성시간/채널/요청자 저장
3. 준비 스레드(또는 준비 컨텍스트) 생성
4. 브리핑 질문 템플릿 출력

### 출력 예시
- 세션 생성 성공
- 현재 상태: `PREPARED`
- 다음 액션: `/room launch`

### 실패 케이스
- `topic` 누락
- 이미 진행중인 세션 존재

---

## 2) `/room launch`

### 목적
워커(소포) 토론 라운드를 시작해 후보안을 발산/비교한다.

### 입력
- 없음

### 선행 조건
- 현재 세션 상태가 `PREPARED`

### 처리
1. 실행 스레드 생성(아이디어 회의실 채널)
2. 워커 토론 라운드 시작
3. 후보안(`A/B/C...`) 생성
4. 각 후보안의 장점/리스크/추정 비용 정리

### 출력 예시
- 라운드 시작됨
- 현재 상태: `RUNNING`
- 다음 액션: `/room status` 또는 `/room summary`

### 실패 케이스
- 활성 세션 없음
- 아직 `/room start` 미실행

---

## 3) `/room status`

### 목적
현재 회의 진행 상태를 즉시 확인한다.

### 입력
- 없음

### 선행 조건
- 활성 세션 존재

### 처리
1. 세션 상태 조회
2. 현재 라운드, 후보안 개수, 미해결 쟁점 조회
3. 최근 업데이트 시각/작성자 조회

### 출력 예시
- 상태: `RUNNING`
- 후보안: `A, B, C`
- 미해결 쟁점: 2개
- 다음 액션: `/room summary` 또는 `/room decide <A|B|C>`

### 실패 케이스
- 활성 세션 없음

---

## 4) `/room summary`

### 목적
결정을 위한 요약 카드를 제공한다. (MVP 포함)

### 입력
- 옵션: `--brief` (짧은 요약), `--full` (상세 요약) *(선택)

### 선행 조건
- 활성 세션 존재 (`PREPARED` 또는 `RUNNING`)

### 처리
1. 현재까지 대화/라운드/후보안 집계
2. 후보안별 핵심 비교 카드 생성
   - 장점(1~2)
   - 리스크(1)
   - 비용/시간 추정
3. 추천안(있으면) + 추천 근거 1줄

### 출력 예시
- 후보안 비교표(요약)
- 추천안: `B`
- 다음 액션: `/room decide B`

### 실패 케이스
- 요약 가능한 데이터 부족(초기 상태)
- 활성 세션 없음

---

## 5) `/room decide <A|B|C>`

### 목적
토론을 종료하고 최종 결정을 확정, 실행 단계로 넘긴다.

### 입력
- `option` (필수): 선택할 후보안 (`A|B|C...`)

### 선행 조건
- 활성 세션 존재
- 선택한 후보안이 현재 후보 목록에 존재

### 처리
1. 최종 결정값 저장
2. 결정 근거(요약/스냅샷) 저장
3. 후속 액션 아이템 생성
4. 필요한 리마인더 생성
5. 세션 상태를 `DECIDED`로 전환

### 출력 예시
- 최종 결정: `B`
- 상태: `DECIDED`
- 생성된 액션: 3개

### 실패 케이스
- 잘못된 옵션 입력
- 후보안 없음
- 활성 세션 없음

---

## 에러 코드 제안
- `ROOM_NO_ACTIVE_SESSION`
- `ROOM_ALREADY_RUNNING`
- `ROOM_INVALID_STATE_TRANSITION`
- `ROOM_INVALID_OPTION`
- `ROOM_MISSING_TOPIC`
