# ROOM flow (start → launch)

> 목적: Slack에서 아이디어 회의(브레인스토밍/의사결정)를 **재현 가능하게** 진행하고,
> 결과물을 **긴 형태의 문서(미니 PRD급)** 로 남기며,
> 필요하면 곧바로 구현(Codex/코딩 에이전트)로 이어지게 한다.

## 핵심 개념

- **room start**: 사람(제완) + 택배(이 오케스트레이터) 1:1 대화로 회의 준비를 끝낸다.
  - 여기서는 대화가 길어져도 됨(단, 최종적으로는 압축됨).
  - 결과: `Launch Brief` (압축된 회의 입력)
- **room launch**: 멀티 모델 API(예: GPT + Claude)를 호출해 토론/검수 결과를 얻고,
  택배가 이를 합쳐 Slack 스레드에 **최종 회의 결과물**로 게시한다.

## 역할 분담(launch 단계)

- **GPT (Builder/Ideator)**
  - 아이디어 확장
  - MVP 설계
  - 구현 로드맵/마일스톤
  - 리스크는 최소한만(“될 것” 중심)

- **Claude (Critic/Editor)**
  - 논리 구멍/가정/엣지케이스 찾기
  - 위험/윤리/약관/현실성 체크
  - 표현/구조를 더 명료하게 정리

- **택배 (Moderator/Editor)**
  - room start에서 정보를 압축해 `Launch Brief`를 만든다.
  - launch 결과를 합본으로 편집/정리해 Slack에 남긴다.
  - 다음 액션(티켓/태스크)로 쪼개고, 일정/리마인더로 연결한다.

## Slack 상의 UX(권장)

- `/room start`는 **준비 스레드**를 만든다.
  - 목표/제약/성공지표/현재 아이디어를 질문 형태로 채운다.
  - 준비 완료되면 택배가 `Launch Brief`를 스레드에 고정(혹은 마지막 메시지로 확정).

- `/room launch`는 (별도 채널을 쓸 경우) **실행 스레드**를 만든다.
  - 1라운드 기준:
    1) `Launch Brief`로 GPT 호출
    2) `Launch Brief`로 Claude 호출
    3) 택배가 두 결과를 합쳐 **최종 결과물 1개**로 게시
  - 원칙: 최종 결과물은 “모델 원문 덤프”가 아니라, 사람이 읽기 좋은 **합본 문서**다.

## Launch Brief 포맷(압축 입력)

room start에서 수집한 내용을 아래 포맷으로 압축해 launch에 사용한다.

- 제목/한줄 목표
- 배경 (왜 지금 이걸 하는지)
- 성공 기준 (측정 가능한 것 1~3개)
- 제약 조건 (시간/리소스/플랫폼/법/약관/데이터)
- 현재 아이디어 (1~3개, 각 3~6줄)
- 비목표(이번 회의에서 하지 않을 것)
- 결정이 필요한 질문(2~5개)

> 주의: 아이디어 뱅크 원문 전체를 넣지 말고 **관련된 항목만 요약**해서 포함한다.

## 최종 결과물 템플릿(슬랙에 남기는 긴 문서)

- 1) 결론 요약(한 화면)
- 2) MVP 스펙(기능/플로우/비기능)
- 3) 구현 로드맵(1주/2주/1달 같은 단계)
- 4) 리스크/가정/대응(Claude 기반)
- 5) 다음 액션(오늘 30~60분 안에 할 수 있는 3개 + 다음 주 3개)
- 6) 미해결 질문 / 다음 회의 아젠다

## 상태/기록(구현 메모)

오케스트레이션은 아래 상태를 저장하는 것을 권장한다.

- `roomId` / `threadTs`(Slack 스레드 식별)
- `phase`: start | launch | done
- `launchBrief` (압축본)
- `models`: gpt, claude 구성과 역할
- `artifacts`: 최종 결과물 메시지 ts, 요약본, 액션아이템 목록

> 토큰/비용 제어는 별도 문서에서 다룬다(여기서는 흐름만 기록).

## Codex(코딩 에이전트) 사용 위치

- room start 단계에서는 택배가 대화/정리/압축을 수행 (일반 대화/정리 작업)
- launch 후, 액션아이템 중 “코드가 필요한 것”이 나오면:
  - Codex를 **Implementer**로 호출하여
  - 레포 변경/스캐폴딩/리팩토링/테스트 작성 등 즉시 구현으로 연결한다.

---

## 결정사항(현재)

- start: 택배와 대화로 준비 → `Launch Brief`로 압축
- launch: 1라운드, **GPT(Builder) + Claude(Critic)** API 호출
- 결과물: Slack에 **길게 남길 것(미니 PRD급)**
